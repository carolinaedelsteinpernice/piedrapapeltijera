# 🪨📄✂️ Piedra, Papel o Tijera

Juego clásico de Piedra, Papel o Tijera desarrollado con HTML, CSS y JavaScript puro.

## 🚀 Funcionalidades
- Selección interactiva entre Piedra, Papel o Tijera.
- Elección aleatoria de la computadora mediante `Math.random()`.
- Evaluación automática del ganador y opción para reiniciar la partida.

## 🛠️ Tecnologías usadas
- HTML5
- CSS3
- JavaScript (ES6)
